# 字習工坊

國小國語學習單生成網站，為資源班及一般班級教師設計。

## 功能
- 國字與詞語練寫、注音填空及國字＋注音學習單
- 國字自動標註注音，支援一字多音人工調整
- 直式注音：分別挖空聲母、介音、韻母、聲調
- 點選符號可挖空，再點可還原；可套用至全部題目
- 編輯插圖、班級、座號與姓名
- A4 自動分頁、作品 JSON 匯入及匯出

## 網站檔案
- `index.html`：目前 V13 網站主程式
- `assets/BpmfZihiKaiStd-Regular.ttf`：網站自己的字嗨注音標楷字型檔案
- `LICENSE-ZihiKaiStd.txt`、`LICENSE-2.0.txt`、`NOTICE.txt`：授權文件
- `.github/workflows/`：同步字型與發布 GitHub Pages 工作流程

本專案獨立於原本的 `zhuyin-practice` 教學網站，兩個儲存庫分開管理。

## 已知待修正問題
V13 的網站畫面與瀏覽器列印／另存 PDF 畫面，可能出現直式注音顯示不一致或注音消失。正式大量印製學習單前請先檢查列印預覽；此問題將在後續版本修正。

## 字型來源及授權
字嗨注音標楷來自 [ButTaiwan/bpmfvs](https://github.com/ButTaiwan/bpmfvs)。字型授權請參閱儲存庫中的授權檔案。

字型由此儲存庫提供，網站不需要從原本的教學網站下載檔案。
